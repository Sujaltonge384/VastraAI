## Upload and commit the screenshots

Copy your screenshots into this folder, open a terminal from the repository root, and run:

```bash
git add docs/screenshots/
git commit -m "docs: add VastraAI screenshots"
git push origin main
```

After the images are pushed, open the root `README.md` and remove the HTML comment markers around the screenshot gallery so the images display on the repository page.

Only add screenshots captured from the real application. Do not add credentials, personal information, or private customer data to screenshots.
